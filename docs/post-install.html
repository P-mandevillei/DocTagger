Start using DocTagger

Open or refresh a Google Doc, then choose Extensions → DocTagger → Open sidebar. Review the data-use disclosure and create or connect a registry to begin tagging.

If DocTagger does not appear in the Extensions menu, refresh the document and confirm that the add-on is installed and authorized.

For detailed setup and troubleshooting, visit DocTagger Support.
