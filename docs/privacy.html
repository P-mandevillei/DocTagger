What the add-on accesses

Doc Tag Index accesses only the Google Doc in which it is being used and the registry Google Sheet that the user creates or chooses. It processes:

  • the current document's ID, title, and URL;
  • managed tag text, property names, and option names;
  • bookmark, named-range, and app-generated occurrence identifiers;
  • registry property definitions, indexed rows, counts, and synchronization times; and
  • an app-specific document property and the user's data-use consent preference.

The add-on does not collect surrounding document passages, user email addresses, contact lists, browsing history, payment data, or credentials.

How data is used

The data is used only to insert and manage visible tags, synchronize tag occurrences to the user's registry Sheet, calculate counts, and provide links back to documents and tags.

Where data is stored

Document content remains in the user's Google Doc. Registry information is stored in the Google Sheet selected by the user. The registry association and consent preference are stored using Google Apps Script properties. The publisher does not operate a separate database or server that receives document or registry content.

Google Apps Script and Google Cloud may retain execution metadata and error information under the publisher's Google Cloud configuration. The application does not intentionally write document content to logs.

Sharing and transfers

Data is processed by Google to operate Google Docs, Google Sheets, Apps Script, and related services. Registry information is visible to people with whom the user shares the registry Sheet. Document content is visible according to the document's sharing settings. The publisher does not sell user data or share it with advertisers, data brokers, analytics providers, or AI model providers.

Retention and deletion

Indexed data remains in the user's registry until the user purges a document from the registry or deletes the registry Sheet. When a tag is removed and the document is synchronized, its former occurrence row is deleted. Users can remove the current document's indexed rows with the sidebar's “Delete this document's registry data” action.

Complete instructions are available on the data deletion page. Users may also revoke the add-on's Google Account access at any time.

Security

The add-on uses Google-hosted Apps Script services and HTTPS. It requests only the permissions needed for its released functionality and does not include third-party runtime libraries.

Google API data

Doc Tag Index's use of information received from Google Workspace APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
