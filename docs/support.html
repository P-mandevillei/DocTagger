Set up a registry

  1. Open a document and choose Extensions → Doc Tag Index → Open sidebar.
  2. Review and accept the data-use disclosure for that document.
  3. Create a dedicated registry or connect a Google Sheet that you control.
  4. Share both the document and registry with collaborators who need them.

Use tags

  1. Add a property name and one or more allowed options.
  2. Place the cursor in editable document text.
  3. Select the property and option, then choose Insert tag at cursor.
  4. Use Sync current document after manual edits or deletions.

Common issues

  • Registry cannot be opened: confirm that you have Editor access to the Sheet.
  • No cursor: click in editable body text before inserting a tag.
  • Collaborator cannot synchronize: share the registry Sheet with that collaborator.
  • Menu is missing: refresh the document and confirm that the add-on is installed and authorized.
