Manage and delete your data

Delete one document's indexed data

  1. Open the document and the Doc Tag Index sidebar.
  2. If necessary, connect the registry that contains the document's index.
  3. Select Delete this document's registry data and confirm.

This removes the document and occurrence rows from the registry and clears the document's registry association. It does not remove visible tags from the document.

Delete the complete registry

Delete the registry Google Sheet from Google Drive. This removes all property definitions, indexed occurrences, summaries, and document records stored in that registry. Google Drive trash and retention behavior continues to apply.

Remove tags from a document

Use the tag's Remove button in the sidebar, or delete its visible text in the document and synchronize. Removed occurrence rows are deleted during synchronization.

Revoke future access

Uninstall Doc Tag Index from Google Workspace Marketplace and remove its connection from the Google Account connections page.
